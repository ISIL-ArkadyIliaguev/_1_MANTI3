# תוכנית עבודה: Access Requests, שני אנשים, יום אחד

**Spec**: [spec.md](spec.md) · **היקף היום:** סוכן ב-Claude Code שמקבל מייל ומחזיר תוכנית וסקריפט SQL. אדם מריץ את הסקריפט.

## איך עובדים
- שניכם יחד על אותה משימה (pair): אחד מקליד, השני בודק ומכוון, ומתחלפים בכל משימה.
- משימה מסתיימת רק כשיש לה תוצר בדיסק ובדיקה שעברה. אחר כך `/clear` ומשימה הבאה.
- כללי הברזל ב-`CLAUDE.md` וב-`.claude/rules/`: DB לקריאה בלבד, מתעלמים מפסילה, יוזר חסר נוצר בסקריפט (שם וסיסמה = מספר עובד, קבוצה 196), עמימות = שאלה, בלי נתוני עובדים אמיתיים ב-repo.

לקחים מהריצות:
- קודים באנגלית מתהפכים במייל בעברית (`N1S` ← `S1N`). נפתר מול ה-DB, לא נחשב שאלה.
- הסקריפט כולל כל הרשאה שהתבקשה לכל עובד, גם מה שכבר קיים (`NOT EXISTS` בזמן ריצה מחזיר הרשאה שנעלמה).
- ה-SPs של MANTI2 להרשאות הם מתגים / דורסים. הסקריפט לא קורא להם.
- הטריגר על `Authorizations` מחתים שורה אחת לפקודה, לכן פקודה לכל מסך.

## אם הזמן לא מספיק
- **קודם מרכז עבודה.** זו שורה אחת בטבלה אחת, ולכן הכי פשוט ובטוח.
- **העתקת הרשאות** יכולה לצאת היום כתוכנית בלבד (מה חסר לעובד לעומת הדוגמא), בלי סקריפט, ולהשלים מחר.
- משימה 3 אפשר לקצר לדוגמה אחת נוספת.
